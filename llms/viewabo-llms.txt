# Viewabo

> Viewabo is an interactive visual product-support platform for modern customer experience, product, and field-service teams. An agent sends a browser link to anyone on-site; the customer taps it and shares their smartphone camera in real time — no app download and no account required — so the support team can see the problem live, guide a remote fix, and confirm whether an on-site dispatch is actually needed.

Notes:
- No public developer API, OpenAPI/AsyncAPI specification, SDK, CLI, or MCP server is published. The `api.`, `developer.`, and `docs.` subdomains redirect to the customer application login.
- The product is delivered as a hosted web application (agents use a desktop browser; customers use any mobile browser with a camera). Pricing is usage-based per video session with unlimited seats.
